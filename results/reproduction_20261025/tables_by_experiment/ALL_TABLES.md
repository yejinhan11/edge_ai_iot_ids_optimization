# 현재 노트북 RF 결과 — 실험 종류별 전체 표

기존 결과를 재현한 **이번 노트북의 측정값**이다. 평가 242행을 모두 포함한다. 기존 성능과의 일치 여부는 [재현 검증 보고서](../REPORT.md)를 참고한다.

정확도·재현율은 %, F1-macro는 0~1이다. 추론은 단일 CPU 스레드의 µs/행이며 특징 추출 시간은 제외한다. 학습은 최대 100만 행(초기 3파일 실험은 50만 행), 시간순 70/30 분할, 시드 42를 사용했다. LOAO는 지정 공격을 학습에서 제외하는 별도 분할이다.

모델 크기는 비압축 직렬화 MB이며 RAM 사용량과 다르다. 평가 대상은 서로 겹칠 수 있다. 동일 학습 설정은 재학습 결과를 공유하므로 표의 같은 시간이 독립 반복 측정값을 의미하지 않는다. 최소 말단 표본 수가 원본에 없던 초기 RF는 코드 기본값 1을 표시했다.

현재 PCAP은 공격 캡처의 첫 2GB 청크 중심이다(HTTP_Flood·SlowLoris·BenignTraffic3 제외). CICIoT2023 전체 원본을 사용한 실험은 아니다. 초기 Colab의 별도 특징 실험은 제외했다.
