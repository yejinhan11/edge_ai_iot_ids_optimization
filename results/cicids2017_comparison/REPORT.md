# CICIDS2017 RF 비교

BENIGN/DDoS 이진 분류. DoS·PortScan·Bot 등은 공격 양성에 합치지 않았다.

**모든 표의 학습·평가 데이터는 CICIDS2017이다.** `legacy_windows`는 CICIoT2023에서 쓰던 38특징·10패킷 방식을 CICIDS2017에 적용한 결과이고, `native_flows`는 CICIDS2017 공식 flow 특징으로 새로 실험한 결과다. 이전 CICIoT2023 데이터의 성능 수치가 이 표에 섞여 있지는 않다.

GitHub에는 코드·문서·지표·그림·설정 및 검증 기록을 포함한다. 원본/가공 데이터·모델 joblib·실행 로그는 기존 제외 규칙에 따라 로컬에만 보관한다. `artifact_validation.json`은 로컬에서 저장 모델을 재로딩해 검증한 기록이다.

## 두 표본 단위

- legacy_windows: 기존 38특징·10패킷 방식. 파일·라벨별 앞 70% 중 80%로 fit, 나머지로 validation, 뒤 30%로 test. 기존에 관찰한 테스트를 고정해서 재사용했다.
- native_flows: 공식 CICFlowMeter 수치 특징. IP·port·Flow ID·Timestamp는 입력에서 제외하고 동일 특징 중복 및 라벨 충돌을 제거했다. 같은 날짜의 양방향 5-tuple 전체를 한 분할에 묶고 시간순으로 나눴다.
- flow와 10패킷 윈도우는 표본·라벨 품질·정제·분할이 다르다. 서로의 F1 차이를 특징만 바꾼 순수 효과로 해석하지 않는다. legacy_windows 안의 baseline/C1–C4/선택 모델은 동일 테스트 표본에서 비교한다.

## 선택 방법

특징 순위·상수 제거·결측치 중앙값·설정 선택은 fit/validation에 한정했다. native 탐색은 30만 fit 표본으로 선별하고 상위 3개와 baseline을 최대 100만 fit 표본으로 재검증했다. 최종 후보를 selection.json에 동결한 다음 앞 70%에서 최대 100만 행으로 재학습하고 test를 평가했다. 선택 모델은 seed 42/43/44로 반복했다.
이번 후보 범위의 검증 최고 설정이며, 모든 가능한 특징·설정의 전역 최적해를 보장하지 않는다.

## LOAO

Leave One Attack Out: 공격 한 종류를 학습에서 빼고, 다른 공격으로 학습한 모델이 빠진 공격을 탐지하는지 평가한다. 현재 BENIGN/DDoS 범위에는 DDoS 라벨이 한 종류뿐이다. 이를 빼면 학습 양성이 없어 이진 RF LOAO는 성립하지 않는다. DoS를 DDoS로 바꾸거나 임의 시간 구간을 공격 종류라고 부르지 않았다.

## 추가 해석

- native의 경량 후보는 검증 macro F1 손실 0.001 이내에서 트리 수·특징 수가 적은 설정을 우선하고, 최대 100만 fit 표본으로 검증한 뒤 테스트했다.
- native 그룹 분할은 같은 날짜의 5-tuple 그룹 첫 시각을 정렬 기준으로 삼는다. 그룹 전체를 보존하므로 개별 flow의 시각 경계가 완전히 분리되는 것은 아니며, 두 방식 모두 엄격한 공통 시각 경계의 미래 예측 평가가 아니다.
- seed 42/43/44 반복은 동일 테스트 분할에서 학습 표본 선택·RF 난수의 변동을 본다. 새 데이터셋이나 새 공격에 대한 반복 검증은 아니다.
- 모델 joblib은 RF 객체 단독이 아니라 model, medians, features, selected_columns를 가진 전처리 포함 묶음이다. 원본 후보 열을 features 순서로 배열하고 medians로 결측을 채운 뒤 selected_columns를 선택해 예측한다.

## 상세 실험 기록 및 CICIoT2023 대비 확인 (2026-10-29)

기존 CSV·JSON을 대조해 보완한 기록이다. 새 RF 학습이나 테스트 재평가는 수행하지 않았다. 비교 기준은 [CICIoT2023 결과 문서의 지정 버전](https://github.com/yejinhan11/edge_ai_iot_ids_optimization/blob/7c864f6cd05dbbcd4c5f8bc46abc748a42dc82f9/docs/RESULTS_ALL.md)이다. 기기별 학습·평가는 현재 연구 범위에서 제외한다.

### 데이터 정제와 분할 수

legacy는 5일 PCAPNG에서 38개 특징·비중첩 10패킷 윈도우를 계산했다. 10패킷 모두 동일한 정상 또는 DDoS 라벨에 매칭되는 윈도우만 보존했다. 다른 공격·누락·모호·혼합 라벨은 제외했다. 총 5,065,637개 중 정상 5,032,072개, DDoS 33,565개다. 공식 flow의 연결·시각을 이용한 매칭이므로 정확한 패킷 단위 정답을 보장하지 않는다. [추출·복구·라벨 검증 기록](../cicids2017_ddos_benign/REPORT.md)을 함께 참조한다.

native는 정상/DDoS에서 잘못된 duration 115행, 특징 동일·라벨 충돌 10행, 특징 동일 중복 409,778행을 제외했다. 정제 후 1,991,221개(정상 1,863,208 / DDoS 128,013)다. 식별자·시각·포트를 제외한 수치 후보 77개 중 fit 상수 10개를 제외해 기준선은 67개다. 결측·무한대는 학습 구간의 중앙값으로 처리했다. [정제 기록](native_preparation.json)

| legacy_windows | fit | 2,817,964 | 18,797 | 2,836,761 |

fit은 사용 가능한 풀의 크기다. legacy 탐색의 실제 학습은 최대 100만 행, native 1차 탐색은 최대 30만 행이다. native 상위 후보 재검증과 두 방식 최종 재학습은 최대 100만 행을 사용했다. 최종 모델은 fit+validation에 해당하는 바깥 학습 풀에서 재표집해 학습한다. 테스트는 표의 전체 행을 평가했다.

### CICIDS2017에서 선택된 특징

native 검증 최고 모델(10개 특징·100트리)의 입력은 다음과 같다. 순서는 저장된 모델의 선택 열 순서다.

`Init_Win_bytes_forward`, `Fwd Packet Length Max`, `Fwd Packet Length Mean`, `Avg Fwd Segment Size`, `act_data_pkt_fwd`, `Fwd Header Length`, `Flow IAT Std`, `Init_Win_bytes_backward`, `Fwd IAT Min`, `URG Flag Count`.

native 경량 모델(20개 특징·20트리)은 위 10개에 다음을 추가한다.

`Flow IAT Min`, `Subflow Fwd Bytes`, `Subflow Fwd Packets`, `Fwd IAT Std`, `Total Fwd Packets`, `Avg Bwd Segment Size`, `Total Length of Fwd Packets`, `Bwd Packet Length Mean`, `Subflow Bwd Packets`, `Bwd Packet Length Max`.

두 native 선택 모델 모두 깊이 무제한·min_samples_leaf=1·class_weight=balanced다. legacy 검증 선택 모델은 38개 전체 특징·50트리·깊이 무제한·min_samples_leaf=1·balanced다. 검증 최고 10개 특징 모델이 테스트에서 전체 67개 특징 기준선보다 낮은 macro F1을 보였다는 점도 그대로 보고한다. 테스트 점수를 보고 검증 선택 모델을 바꾸지 않았다.

### 보고서에서 사용할 해석과 남은 범위

현재 결과는 이번 데이터 정제·분할·탐색 범위에서의 RF 기준선 및 경량화 비교로 사용할 수 있다. 전역 최적 성능이나 새로운 공격에 대한 일반화가 증명된 것은 아니다. native 경량 모델은 기준선 대비 RF 추론이 약 6.3배 빠르고 macro F1 차이는 약 0.000087(0.0087%p)이다. 이는 동일 native 테스트에서의 RF 비용 비교다.

CICIoT2023와 CICIDS2017 수치를 나란히 제시할 때는 데이터·클래스 비율·표본 단위·정제·분할 차이를 함께 기록한다. 특히 지정 CICIoT2023 실험은 캡처의 첫 2GB 청크 중심이었고, CICIDS2017 legacy는 5일 전체 캡처에서 보존 조건을 만족한 윈도우다. 점수 차이만으로 어느 데이터셋에 더 강한 모델이라고 결론 내릴 수 없다.

남은 검증은 엄격한 공통 시각 holdout, 독립 공격 실행·다른 데이터에 대한 일반화, legacy 연결의 train/test 경계 중복 영향, 패킷 수집부터 특징 추출·flow 대기까지 포함한 실제 edge 지연이다. 이는 이미 끝낸 변수 탐색이 누락됐다는 뜻이 아니라 현재 결과가 답하지 않는 추가 연구 범위다. 기기별 실험은 제외하며, 현재 DDoS 범위에서 LOAO를 억지로 추가하지 않는다.
