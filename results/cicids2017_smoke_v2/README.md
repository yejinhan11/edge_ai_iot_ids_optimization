# CICIDS2017 준비 검증 (2026-10-26)

5개 실제 PCAPNG에서 각각 앞 20,000패킷, 총 100,000패킷을 읽었다. 기존 특징 추출기와 라벨 매칭 파이프라인으로 38개 float32 특징의 완전한 10패킷 윈도우 8,672개를 저장했다. 모두 캡처 시작부의 BENIGN이며 공격 성능을 평가한 결과가 아니다.

| Wednesday | 1,903 | 19,310 | 2 | 125.7 |
| Thursday | 1,791 | 18,438 | 0 | 71.4 |

표의 매칭·미매칭은 추출 대상 IPv4/ARP 패킷 중의 수다. 나머지에는 unsupported와 fragment가 있고, IPv6 등 추출 비대상 패킷은 포함하지 않는다. 상세 분모와 제외 건수는 `extraction_metadata/*.json` 참조. 학습 데이터는 `data/*.parquet`이며 git에서는 제외된다.

전체 라벨 CSV를 일자별로 읽는 과정에서 음수 duration 행은 월/화/수/목/금 각각 15/17/21/15/47개를 제외했다. 목요일 CSV에는 필수 매칭 필드가 누락된 행 288,602개가 있어 제외했다. 제외 행을 정상 라벨로 바꾸지 않았다.

검증:

- 실제 5개 파일 PCAPNG magic 판별, Ethernet 읽기, 기존 추출기 계산, 10패킷 단위 라벨 정렬, parquet 저장 통과.
- `src/test_cicids2017.py` 4개 테스트 통과. 정상·공격 합성 PCAPNG에서 순/역방향 flow 매칭, 시간 구간·충돌·미매칭·혼합 제외, 38개 특징, 100-tree RF 학습 및 결과 저장 확인.
- 정상만 있는 실제 smoke 데이터는 기존 학습기의 두 클래스 검사로 중단됨을 확인했다. 무의미한 정상 전용 RF 성능 결과는 생성하지 않았다.
- Python 구문 검사 및 `git diff --check` 통과.

smoke는 순차 실행 중 필수 필드 누락 처리 보완 후 나머지 일자를 이어 실행했다. 파일별 실제 사용 코드 해시는 JSON에 기록되어 있으며, 마지막 메타데이터 필드 추가 이후 버전과 다를 수 있다. 수식·윈도우·매칭 정책은 같다. 최종 명령과 정책은 `docs/CICIDS2017_RF.md` 참조.

전체 약 52GB 추출과 최종 RF 학습은 미실행이다. 표본별 처리 시간이 크게 달라 전체 실행은 수 시간~하루 이상을 예상해야 하며, 실제 공격 구간 매칭률과 클래스별 보존율은 아직 검증하지 않았다. 분 단위 라벨 시각으로 인한 후보 매칭의 한계도 남는다.
