# CICIoT2023 RF 재현 확인

기존 가공 데이터 `data/processed/dataset_v1_parts/`에서 RF를 다시 학습한다.
PCAP 특징 추출을 반복하는 검증은 아니다. 기존 결과 파일은 수정하지 않는다.

프로젝트 루트에서 실행:

```powershell
.\.venv\Scripts\python.exe -u src/reproduce_rf.py
```

결과는 `results/reproduction_20261025/`에 저장한다. 날짜는 최초 실행일이다.
같은 설정은 재학습을 공유하며, 완료된 설정의 JSON을 읽어 중단 후 재개할 수 있다.
입력 데이터·코드·설정을 변경한 경우에는 기존 캐시로 재개하지 말고 새 출력 폴더를 사용한다.

- `environment.json`: 이번 Python·라이브러리 버전, 설정 가정, 원본 결과 및 코드 해시.
- `rf_*.csv`, `sweep_*.csv`: 재실행 평가 결과. 모델 파일은 저장하지 않는다.
- `comparison.csv`: 원본과 재실행의 지표별 값·차이·일치 여부. 파일별 완료 즉시 갱신한다.
- `summary.json`: 전체 실행이 정상 완료되었을 때 생성하는 최종 집계.
- `config_*.json`: 완료된 개별 학습 설정의 평가 캐시.

비교 대상은 기존 `rf_*.csv` 평가 101행과 `sweep_*.csv` 평가 141행이다.
`rf_comparison.csv`와 `final_candidates.csv`는 기존 평가를 모은 파생 표라 별도 학습 대상이 아니다.
초기 `test3`는 `dataset_test3_summary.csv`의 세 파일에 해당하는 가공 행을 사용한다.
`data/legacy/rf_full_vs_camera_result.csv`는 과거 Colab의 다른 특징·처리 방식에 따른 결과이며
해당 학습용 특징 캐시가 없어 이번 검증에 포함하지 않는다.
특징 중요도 CSV 자체의 재현 비교와 모델 바이너리 비교도 이번 지표 검증의 범위 밖이다.

행 수·혼동행렬·트리 수·노드 수·최대 깊이는 정수의 완전 일치를 확인한다.
정확도·precision·recall·F1 등은 완전 일치와 절대 오차 `1e-12` 이내 여부를 함께 기록한다.
CSV 읽기와 부동소수점 계산 때문에 마지막 자릿수만 달라질 수 있다.
혼동행렬의 일치만으로 개별 행의 예측까지 같다고 증명할 수는 없다.
과거 개별 예측 파일과 라이브러리 버전 기록이 없어 그 수준의 동일성은 확인할 수 없다.

학습 시간·추론 시간·메모리는 PC와 실행 시점에 따라 달라지는 측정값이다.
모델 크기는 직렬화 환경에 영향을 받을 수 있어 별도 항목으로 비교한다.
기존 실행의 seed·분할 비율 기록은 CSV에 없으므로 코드 기본값인 42·0.7을 사용하며,
이 가정도 `environment.json`에 남긴다. 학습 행 상한은 각 원본 표의 `train_rows`를 사용한다.
